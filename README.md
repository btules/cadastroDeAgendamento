# 📅 Sistema de Cadastro de Agendamentos

Aplicação desktop desenvolvida em Java utilizando Swing para construção da interface gráfica e MySQL para persistência dos dados.

O projeto foi desenvolvido sem a utilização de frameworks, aplicando diretamente conceitos de programação orientada a objetos, construção de interfaces gráficas e integração com banco de dados relacionais.

## 🛠️ Tecnologias utilizadas

- **Java:** linguagem utilizada no desenvolvimento da aplicação.
- **Java Swing:** biblioteca utilizada para construção da interface gráfica desktop.
- **JDBC:** API utilizada para comunicação entre a aplicação Java e o banco de dados.
- **MySQL:** banco de dados relacional utilizado para armazenamento das informações.
- **MySQL Connector/J:** driver responsável pela conexão com o MySQL.

## 🎯 Conceitos aplicados

- Programação orientada a objetos (POO).
- Desenvolvimento de aplicações desktop.
- Construção de interfaces gráficas com Java Swing.
- Integração com banco de dados relacionais.
- Persistência de dados utilizando JDBC.
- Organização de código Java sem dependência de frameworks.
